Zero-Trust Security Architecture

Full-spectrum defense against prompt injections, rogue tool calls, and credential leakage.

01

Destructive Command Interception

AST-level pre-execution matching intercepts commands like rm -rf /, DROP TABLE, chmod 777, and force pushes before they execute.

02

In-Stream Zero-Latency DLP

Sub-millisecond regex scanning automatically scrubs AWS access keys, OpenAI tokens, GitHub PATs, JWTs, and database URIs from tool arguments and outputs.

03

Transparent stdio / SSE Proxy

Zero code modifications needed. Wraps any existing service binary seamlessly with less than 0.5ms inspection overhead.

04

Configurable Enforcement Modes

Run in enforce mode to reject malicious requests, audit mode for non-blocking compliance logs, or permissive mode for in-place data masking.

Drop-in Integration

Secure Claude Desktop, Cursor, or your custom Node.js agents in seconds.

# Wrap any tool server directly from the command line
aegis -- npx -y @modelcontextprotocol/server-postgres postgresql://localhost/mydb

# Run in audit mode without blocking execution
aegis --mode=audit -- npx -y @modelcontextprotocol/server-filesystem /Users/me
