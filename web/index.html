Engineered for Zero-Trust Agent Security

Keep your production infrastructure safe from prompt injections, hallucinations, and rogue subagents.

🛑

Destructive Command Interception

Pre-execution AST parsing stops dangerous commands like rm -rf /, DROP TABLE, chmod 777, and force pushes before they reach the OS shell or database.

🔐

In-Stream Zero-Latency DLP

Automatically scrubs AWS keys, OpenAI API tokens, GitHub PATs, private SSH keys, and connection passwords from tool call arguments and responses in-flight.

⚡

Transparent stdio / SSE Proxy

Zero code modifications required. Wraps any existing MCP server binary seamlessly with less than 0.5ms inspection overhead.

🎯

Configurable Enforcement Modes

Run in enforce mode to block risky actions, audit mode for zero-interruption compliance logging, or permissive mode for live secret sanitization.

Drop-in Integration

Wrap any existing MCP server in seconds.

# Wrap any MCP server directly from the command line
mcp-shield -- npx -y @modelcontextprotocol/server-postgres postgresql://localhost/mydb

# Run in audit mode without blocking execution
mcp-shield --mode=audit -- npx -y @modelcontextprotocol/server-filesystem /Users/me
